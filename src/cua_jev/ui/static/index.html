EXTERNAL BASELINE

Codex Computer Use 接入约定

CUA-JEV 不会用 Rule 冒充 Codex。Codex Computer Use 必须执行同一任务，并通过相同终态 Verifier，再把真实耗时、动作数和通道计数写入 baseline API。

POST /api/baselines
{
  "agent": "codex_computer_use",
  "task": "edge",
  "action_space": "gui_only",
  "success": true,
  "duration_ms": 42000,
  "actions": 8,
  "channels": {"gui": 8},
  "verifier": "shared_terminal_verifier"
}
