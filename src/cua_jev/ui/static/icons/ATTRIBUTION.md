# Third-party application icons

The Edge and Visual Studio Code icons on the project page identify the applications used in the recorded workflows. Their trademarks belong to Microsoft Corporation; their inclusion does not imply endorsement.

- `edge.svg`: Microsoft Edge product icon, sourced from [Wikimedia Commons](https://commons.wikimedia.org/wiki/File:Microsoft_Edge_logo_(2019).svg). Microsoft’s [Edge icon guidance](https://cdn-dynmedia-1.microsoft.com/is/content/microsoftcorp/microsoft/mscle/documents/presentations/Microsoft_Edge_trademark_guidelines_2026.pdf) describes this blue-green swirl as the browser product icon. The Commons file lists Microsoft Corporation as author and the Expat/MIT License below.
- `vscode.svg`: unmodified stable icon from Microsoft’s [official Visual Studio Code branding download](https://code.visualstudio.com/brand). Use is subject to the branding guidelines on that page.
